# Cyber-Project

A secure document locker web application built for cyber security testing and secure file management.

## Features
- User authentication
- Secure file upload and storage
- Folder management
- File sharing
- Activity & audit logs
- Input validation against attacks (SQL Injection, XSS)

## Tech Stack
- React
- TypeScript
- Node.js
- Supabase
- Tailwind CSS

## Installation

```bash
npm install
npm run dev
